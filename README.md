# Mobile Export

Mobile Export is an Obsidian plugin for exporting notes as PDF or HTML on mobile devices.

## Usage

Open the context menu for a note or inside the editor, then select **Export**. Choose PDF or HTML and select **Export**. PDF export supports several page sizes and page orientation options.

## Development

Install dependencies and build the plugin with npm:

```bash
npm install
npm run dev
```

For a production build, run `npm run build`. The build creates `main.js` in the plugin folder.
